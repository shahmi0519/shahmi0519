### 🚀 Featured Project — Arxia

> **ArXiv AI/ML Research Assistant** — an agentic RAG chatbot built from scratch and deployed to production.

Arxia lets you have deep conversations about landmark AI/ML research papers. It uses hybrid retrieval (semantic + keyword), a two-layer memory system, and a 5-category intent classifier to route queries intelligently.

| Layer | Tech |
|---|---|
| LLM | Google Gemini 1.5 Flash |
| Embeddings | HuggingFace `sentence-transformers/all-MiniLM-L6-v2` |
| Vector store | FAISS + BM25 (EnsembleRetriever, 60/40) |
| Memory | SQLite (long-term) + LangChain ConversationBufferWindowMemory (short-term) |
| Backend | FastAPI on AWS EC2 |
| Frontend | React + Vite on Vercel |
